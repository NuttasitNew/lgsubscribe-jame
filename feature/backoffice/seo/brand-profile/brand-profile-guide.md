# ชุดอ้างอิงบริษัทสำหรับ AI

เปิด `/super-admin/hurry-web/brand-profile` จากเมนูชุดอ้างอิง AI หรือจากหน้าสร้างภาพ

## วิธีใช้งาน

- แนวทางภาพของบริษัท: ดูรายละเอียด → แก้ไข System prompt → ตรวจสอบก่อน–หลัง → ยืนยันบันทึก
- รูปอ้างอิง: คลิกรูปเพื่อดูรายละเอียด → แก้ไขชื่อ ประเภท คำอธิบาย เปลี่ยนภาพ หรือพักการใช้งาน → ตรวจสอบ → บันทึก
- รูปใหม่: เพิ่มรูปอ้างอิง → อัปโหลดและอธิบายสิ่งที่ต้องเหมือนภาพ → ตรวจสอบ → บันทึก
- ทุก phase ใช้ dialog เดียว สลับเนื้อหาทั้งพื้นที่ กดกลับไปแก้ไขแล้วค่าที่พิมพ์ยังอยู่
- เปิดใช้งานได้ 8 รูป เก็บได้ 16 รูป รองรับ PNG/JPEG/WebP ไม่เกิน 10 MB ต่อรูป ใช้ภาพเต็ม ไม่ crop ภาพอ้างอิง

## การนำไปใช้

แนวทางและรูปถูกเก็บใน HurryWebBrandProfile พร้อม revision, ผู้บันทึก และเวลา การบันทึกตรวจ revision เดิมเพื่อป้องกันเขียนทับงานของผู้ดูแลคนอื่น หากเกิด conflict ฟอร์มยังอยู่ ให้คัดลอกสิ่งที่ต้องการเก็บแล้วเปิดข้อมูลล่าสุดก่อนแก้ใหม่

การสร้างภาพหน้าเว็บและภาพถ่ายบทความอ่านข้อมูลที่บันทึกจากฐานก่อนเรียก AI ไม่เปลี่ยนภาพที่สร้างไปแล้ว ภาพอินโฟกราฟิกของบทความใช้แนวทางแผนภาพเดิม ไม่แนบภาพถ่ายยูนิฟอร์ม/เครื่อง โหมดไม่มีคนและเครื่องของหน้าเว็บแนบได้เฉพาะ reference ประเภทโทนภาพ

ไม่มี record ใช้ชุดบริษัทเริ่มต้น หากฐานอ่านไม่สำเร็จจะแสดง error ไม่ย้อนกลับไปใช้ภาพเก่าโดยไม่แจ้ง รูปที่อัปโหลดใช้ชื่อไฟล์ใหม่ จึงไม่เขียนทับไฟล์อ้างอิงเก่า ยกเลิกฟอร์มหลังอัปโหลดไม่เปลี่ยนชุดที่ AI ใช้ แต่ไฟล์ที่อัปโหลดแล้วอาจยังอยู่ใน storage
