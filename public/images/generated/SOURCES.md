# Generated homepage assets

## Calculator product composites

The calculator uses one finished raster composite per selectable product. Both images were created with the built-in image generation tool from a generated room background plus the matching unmodified official LG Thailand packshot documented in [`../products/official/SOURCES.md`](../products/official/SOURCES.md).

- `calculator-water-purifier-composite-v2.png` — combines `calculator-water-purifier-bg-v1.png` with the official WD516AN packshot. The prompt preserves the kitchen counter and integrates the purifier with matching under-shelf light, counter reflection, perspective, and contact shadow while excluding white cutout edges, text, badges, and extra products.
- `calculator-washer-composite-v2.png` — combines `calculator-washer-bg-v1.png` with the official FV1413S4M packshot. The prompt preserves the laundry room and integrates the washer at installation scale with matching daylight, perspective, floor reflection, and contact shadow while excluding white cutout edges, text, badges, and extra appliances.
