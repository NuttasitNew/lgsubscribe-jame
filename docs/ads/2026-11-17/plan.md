# 17 พ.ย. 2569 — แคมเปญโปร LG Subscribe ฉลองครบรอบ 2 ปี (16–30 พ.ย. 69)

บัญชี: Lg Authorized Dealer (758-859-7274) · ต่อจาก [13 พ.ย.](../2026-11-13/changes.md)
สถานะ: **เปิดแล้ว 17 พ.ย. 2569** — campaign ID `24468071016` สถานะ "มีสิทธิ์ (กำลังเรียนรู้)"
(หน้า `/subscribe-anniversary/` ขึ้น production ก่อนเปิดแอด ตอบ 200)

Google ประเมินตอนสร้าง: ~12–13 คลิก/สัปดาห์, CPC เฉลี่ย ~฿12–13, ใช้จริง ~฿155/สัปดาห์
→ คำโปร/รายเดือนมีคนค้นน้อย งบ ฿250/วันน่าจะใช้ไม่หมด (Google แนะนำ ~฿22/วัน)

## Thesis

คนที่ค้นคำโปร/ส่วนลดของ LG Subscribe และคำ "เครื่องใช้ไฟฟ้า LG รายเดือน" ช่วงโปร 16–30 พ.ย.
เมื่อเจอข้อความ "ลดเพิ่ม 10%" + หน้าโปรที่โชว์ราคาเดือนแรกหลังลด จะกดแอดไลน์มากกว่าหน้าแรกปกติ

- Baseline: ต.ค. ฿619 ต่อ conversion (ทั้งบัญชี) ; Campaign #1 7 วันก่อน 13 พ.ย. ฿240 ต่อ conversion
- เกณฑ์ผ่าน: ต้นทุนต่อ conversion ≤ ฿400 ภายใน 30 พ.ย. (ใช้งบรวมไม่เกิน ~฿3,500)
